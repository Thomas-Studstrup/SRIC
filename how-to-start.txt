Start med at gå i SRIC\app mappen og skriv:

Aktiver miljø:
venv\Scripts\activate

Installer dependencies (hvis ikke gjort):
python -m pip install -r requirements.txt      

Start database:
python db/init_db.py

Start app:
uvicorn main:app --reload
